An entry for the [make.fun The One-Line Laugh bounty](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) ($5 USDC, top 3 paid $2/$2/$1). A small Node 22 program that writes exactly one funny line — a single sentence of at most 200 characters — to `/output/entry.txt`.

## The line

> I asked my AI assistant for a compliment and it said, 'you type with remarkable confidence for someone who Googles everything.'

## Run

```sh
node main.ts
```

This writes the line to `/output/entry.txt` and verifies it is a single sentence of 1–200 characters.
